The browser sends the token as ?subscription_token=… on the websocket. The consumer verifies the signature, checks scope["user"] matches the bound user, and subscribes — without consulting the authorizer, since the token is already proof.

If you copied the token into another browser session you'd find that opening the same websocket subscribes nothing: the bound user wouldn't match.
